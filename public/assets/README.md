# Website asset library

All browser-served assets live under this directory.

- `audio/` — site music and sound files
- `images/profile/` — portraits and profile imagery
- `images/projects/` — project gallery imagery
- `images/certificates/` — certificate scans
- `images/achievements/` — achievement gallery imagery
- `images/stickers/` — decorative sticker artwork

Use absolute paths beginning with `/assets/` in application data and components.
